# dbdoctor 🩺
Open-source database performance diagnosis platform with intelligent recommendations for PostgreSQL, MySQL, Oracle, MongoDB, and more. You can instantly identify slow queries, missing indexes, and optimization opportunities.

## ✨ Features

- 🔍 **Query Analysis** - Identify slow queries and execution bottlenecks
- 📊 **Performance Metrics** - Real-time monitoring of CPU, memory, and I/O
- 🎯 **Index Recommendations** - Discover missing and unused indexes
- 📈 **Visual Dashboards** - Beautiful, interactive performance charts
- 🔌 **Multi-Database Support** - PostgreSQL, MySQL, Oracle, MongoDB, SQL Server
- 🚀 **Optimization Suggestions** - AI-powered recommendations for better performance
- 📱 **Modern UI** - Built with Next.js 16 and Tailwind CSS
